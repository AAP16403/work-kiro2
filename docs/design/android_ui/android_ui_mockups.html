PLOUTO · Android UI

Landscape touch layouts for every screen, drawn at 1 CSS px = 1 dp inside each device frame. Implementation plan: docs/plans/ANDROID_PLAN.md. Layout rationale: docs/design/ANDROID_LAYOUT_HYPOTHESIS.md.

These are design mockups. Nothing here is implemented in the Rust game, and no layout has been checked on a real phone. Names for skins, weapons, rewards, mutators, bosses and achievements come from the source. Numbers, achievement targets and Field Guide text are sample copy.

Layout rules

  • Touch targets ≥ 48 dp (combat buttons ≥ 60 dp visual, 68 dp hit), with ≥ 8 dp gaps between targets.
  • 8 dp grid. The screen margin inside the safe area is 8 dp. Panels have a 10–14 dp radius.
  • Safe area: cutout, system bar and gesture insets, plus a 16 dp cutout margin. The arena still draws full-bleed.
  • Taps fire on release inside the same target, and are cancelled after 10 dp of movement (scroll wins).
  • Back: closes a sheet or dialog, then goes to the previous screen. In a run it pauses. On the main menu it asks to exit.
  • Don't rely on color alone: every state also changes its icon, fill or outline.

Layout

  • Columns are 45 / 55 of the safe width, with 16 dp between them.
  • PLAY is 60 dp tall. The other buttons are 48–56 dp.
  • The PLAY subtitle shows the current difficulty and arena, so they don't need to open Settings first.

Mutators

  • The chips scroll horizontally, are 40 dp visual / 48 dp hit, and fade at the right edge to hint that more are available.
  • Active chips get a ✓ and a red outline, not color alone.

Changes from desktop

  • The centered button column is replaced by a right-hand stack.
  • Quit is removed. Hover highlight becomes a pressed state.
  • Tablet: the same structure, at a maximum width of 1100 dp.

Top band (status)

  • Vitals: 196×52 dp, top-left. Hull and Shield only; Boost energy lives on the Boost button.
  • Wave · score: first line right of the vitals, 13 sp. Long scores shorten to "48.2k".
  • Second line (right of the vitals): Auto-fire chip (48 dp hit), up to 6 buff/relic badges plus a "+N" chip, then the weapon with reload pips. The skin label is dropped on touch.
  • Event line: centered just below the 52 dp status band, fades when the event ends.
  • The whole status band is 52 dp tall, so action buttons can sit high on either side in left-handed mode.
  • Combo + pause: top-right. Pause is 48×48 dp.

Controls

  • Placement: every control is anchored in dp from its bottom corner, not by screen percentage, so the thumb cluster stays together on tablets and wide phones.
  • Sticks: 160 dp ring, 64 dp knob, 0.18 radial deadzone (dashed). They float within the zones (turn on "Stick zones"). At rest they show at the last-used spot at 55% opacity.
  • Dash (tap) shows a live cooldown ring. Boost (hold) shows a live energy ring. Ultra (tap) is 64 dp with charge pips and the existing cooldown radial.
  • Rings read sim state directly. There are no hard-coded timers.

Behavior

  • Each finger owns the control it first touched until it lifts. A third finger can use the buttons.
  • Auto-fire on: fire continuously, and keep the last aim on release. Off: fire while the aim stick is pushed past 50%.
  • Left-handed mirrors only the controls; the top band stays put.

Boss band

  • Centered just below the status band. The bar is 34% of the safe width and 14 dp tall. A tick marks the next phase threshold, and the name and phase label sit underneath.
  • It's only drawn during a boss; there's no empty placeholder otherwise.

Collapse order (when crowded)

  • 1. Combo drops its decay bar. 2. Score shortens. 3. Badges past 4 become "+N". 4. The weapon name shortens to its icon.
  • Never hidden: hull, shield, boss bar, pause, Auto-fire state, or reload.

Danger states

  • Low hull (≤ 35%): the vitals panel glows red and the number turns red. With reduced motion it's a static outline.
  • Dash on cooldown: the icon dims, the ring fills, and a small number appears only when ≥ 0.5 s remain.
  • Ultra ready: gold glow. The pulse is disabled under reduced motion.

Cards

  • Each is about ⅓ of the safe width (about 260 dp on 20:9). The title is 16 sp, the description 15 sp, and the text wraps without cutting off.
  • The tag (TEMPORARY / PERMANENT / NEW RELIC) uses an outline style plus a word, not just a color.

Guards

  • A 400 ms input lock. Pointers that were already down when the screen opened are ignored.
  • Two-step: select, then TAKE. Double-tapping the same card also confirms.

Tablet

  • The cards cap at 300 dp wide and center. TAKE moves under the selected card.

08 · Settings SettingsScreen · the tabs work

The two fixed desktop columns become a tab rail on the left and a scrolling list on the right. Window size and fullscreen are hidden on Android. There's a new Controls tab for touch.

SETTINGS Changes save automatically

Structure

  • The rail is 176 dp with 48 dp tabs. The list scrolls with inertia and fades top and bottom.
  • Toggle rows are 56 dp. Slider rows have a 40 dp drag track and a 26 dp thumb, with the value shown on the right.

New touch settings

  • Handedness, stick mode, control size (0.8–1.3), opacity (0.3–0.9), touch deadzone (0.05–0.4), haptics, "Customize layout…" (opens 09), and "Replay tutorial".

Android-only display

  • Graphics quality (Low/Med/High), frame rate (30/60), HUD size (0.85–1.25). Fullscreen and window size are hidden.

Rules enforced

  • Controls stay inside the safe area, out of the top 60 dp status band, and outside the stick rings, with ≥ 8 dp between hit areas.
  • Each position is saved as a fraction of the safe area, so it carries over between devices.

Actions

  • RESET returns to the default layout. MIRROR flips handedness. S/M/L sets control size. DONE saves.
  • Back without DONE asks "Discard changes?"

12 · Field Guide GuideScreen · the tabs and list work

A list and a detail panel replace Prev/Next paging. The list is 36% of the width and scrolls. The detail panel shows the role, a description and counterplay tips.

FIELD GUIDE

Tabs

  • Desktop has Enemies, Power-ups, Basics and Systems. On touch, Bosses gets its own tab because boss counterplay is the most-read content. Systems moves under Basics.

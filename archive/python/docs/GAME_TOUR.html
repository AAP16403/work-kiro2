A survival shooter, from the code up

PLOUTO

An isometric shooter about a small pod robot in a round arena, fighting waves that never stop coming. Shoot, dash, collect, and survive. Everything below is taken from the game itself: the screens, the frame loop, the enemies, the guns, the power-ups, and the code that holds them together.

Heartbeat

One frame, step by step

The simulation never trusts the window's frame rate. It runs fixed steps of one sixtieth of a second and catches up at most six at a time, so a slow frame cannot make the game jump. Each step runs the stages below in this order. Pick one, or let the playhead walk.

Screens

Eight screens, one state machine

Every screen is a state with its own enter, update, and draw. A small state machine holds the current one and moves between them. Click a screen to see what leads to it and where it leads.

Arsenal

Seven guns, seven moods

Each weapon has its own bullet, trail, and impact. The little demos loop the real effect: tracers, spreads, the rapid stream, the heavy slug with its smoke, the plasma orb, the railgun streak, and the flak shell that bursts in a shockwave. Flak is held back until wave 7, because it is the top rank.

Power-ups

Things you pick up

Power-ups come in tiers. Common ones drop often. Rare ones are timed, and rare ones show their timers on the HUD. Weapon pickups are upgrades only: a lower-ranked gun never replaces a better one, and they revert after 20 seconds. The two newest, Chain Lightning and Repulsor, are built and wired into the run.

Hangar

Skins for the pod

Pick a skin in the Hangar and the pod wears it in the next run, including the shots it fires. Some skins unlock by earning achievements. The colours below are approximate, drawn for this page, not sampled from the game.

Multi-core

Work spread over the cores

The game keeps the window on one thread, because OpenGL draws there. Other work moves to processes and threads. Batched enemy steering runs on three worker processes once a wave reaches sixteen enemies. Move the slider to see the switch.

Saves and build

Your progress survives a rebuild

Three files hold what the game remembers: progress, settings, and the best scores. Every rebuild moves them into a backup folder first, then puts them back into the new build after the zip is made, so the zip never carries anyone's save. Press the button to watch it happen.

PLOUTO is a Python game built on pyglet 2.1.19, packaged with PyInstaller for Windows.

This page is a model drawn from the code. The game itself has the numbers, and the real visuals live in the game.

Honest notes: Chain Lightning and Repulsor are tested in a real run but not yet playtested by a person. The steering pool is switched on for crowds of 16 or more; a bench measured it at 1.7 to 3.5 times faster than serial from 32 enemies up, and roughly even at 16.

# Python game archive

This folder preserves the earlier Python implementation and its supporting materials. It is retained for reference and feature history; the Rust workspace at the repository root is the active game and release target.

- `*.py` files at this level are the former desktop game modules.
- `tests` contains the archived Python checks.
- `tools` contains the old playtest, capture, balance, build-support, and audio-generation tools.
- `enemy_behaviors` contains Python enemy and boss logic.
- `vercel_site` contains the archived browser game.
- `docs` contains the former Python project guide, release notes, and design documents.
- `build` contains the former Python package configuration and dependencies.

The `assets` folder remains at the repository root because the Rust game uses its fonts and audio files. Local save files also remain at the root so the Rust game can continue using them.

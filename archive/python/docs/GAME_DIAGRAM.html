3. One frame: update and draw (game.py, states.py PlayingState)

The simulation runs in fixed steps of 1/60 s. Rendering runs once per window frame, after the steps.

flowchart TD A["Game.update(dt)
clamp dt, audio.update, popups.update, hud.tick"] --> B["accumulate time
fixed step 1/60, at most 6 catch-up steps"] B --> C["fsm.update(1/60)"] C --> D{"current state is PlayingState?"} D -- no --> E["state.update

time slow sets the enemy time scale"] F2 --> F3["boost and dash input"] F3 --> F4["traps, thunders, arena event update"] F4 --> F5["player move, dash, shield regen, clamp to room"] F5 --> F6["auto fire: weapon cooldown, shots"] F6 --> F7["drone update and drone shots"] F7 --> F8["enemies: batched steering if live count is 16 or more, else serial"] F8 --> F9["enemy shots and boss attacks"] F9 --> F10["player bullets vs enemies, enemy bullets vs player, hazards"] F10 --> F11["power-up pickups, magnet pull"] F11 --> F12["wave clear, next wave, boss, power-up drops"] F12 --> F13["particles update, HUD state, player death check"] F13 --> G["on_draw: fsm.draw"] G --> G1["visuals.sync_scene, sync_drone, sync_juice"] G1 --> G2["HUD, popups, screen fade"]

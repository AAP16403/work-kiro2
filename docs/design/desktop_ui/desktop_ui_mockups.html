PLOUTO · Desktop UI

A redesign of every desktop screen for mouse, keyboard and gamepad. Each frame is a game window at the selected size. The UI inside is laid out at a 1280×720 reference and scaled by u = min(W/1280, H/720), the same idea as ui_scale in ui/theme.rs. Wider windows get more horizontal room instead of bigger widgets.

These are design mockups and nothing here is implemented. Names for skins, weapons, rewards, mutators, bosses and achievements come from the source. Scores, counts, timers and Field Guide text are sample copy. Key rebinding (Settings → Controls) is a proposed feature; the current game has fixed bindings.

Companion: Android mockups in docs/design/android_ui/android_ui_mockups.html.

Desktop rules

  • Every screen works from the keyboard and gamepad alone. One element always has focus, shown by a white ring plus an accent fill. Hover only tints.
  • Key hints in a footer on every screen, swapped automatically to gamepad glyphs when the pad is the active device (existing InputDevice).
  • Mouse hit areas ≥ 32 px tall; primary buttons 40–54 px.
  • Esc / B always goes back one level; on the main menu it focuses Quit rather than quitting.
  • The combat HUD stays in the corners. The center 50% of the screen is for the fight, the cursor and telegraphs.

Layout

  • Brand and records take the left 60%, and a 440 px navigation column sits on the right, vertically centered.
  • Nav rows are 48 px, each with an icon, a label and live context (difficulty, daily state, equipped skin).
  • The mutator panel sits under the nav. Its description line follows hover or focus.

Changes from current desktop

  • Current: a centered 230 px button column with a single chip row along the bottom and no context. New: a two-pane layout, a last-run card, and a score-multiplier readout for mutators.
  • Field Guide moves above Settings, since new players need it more.

Input

  • ↑/↓ or W/S or the D-pad move focus. Enter or A selects. jumps to the mutator row, where ←/→ move and Enter toggles.
  • Esc or B focuses QUIT instead of quitting (matches the current "B does nothing on the main menu" rule).

Layout

  • Cards are up to 330 px wide, with art, a type tag (word plus outline), title, description and duration. The TAKE button repeats the selected card's name.

  • Larger cards with art and a duration line. The selection gets a white focus ring as well as gold, and a 1-of-2 step bar is added.

Layout

  • 210 px tab rail, a scrolling list, and a 300 px help panel. Rows are 50 px. Sliders get a fixed 220 px track and a numeric value.
  • On 2560×1080 the extra width goes to the list, and the help panel stays 300 px.

Changes from current desktop

  • Current: two fixed columns of chips and sliders in one panel. New: grouped tabs, row-level help, Reset tab, and a rebinding table with conflict warnings (new feature).

Input

  • Enter on a binding cell starts listening ("Press a key…"). Esc cancels. A key already in use shows a red conflict with a swap prompt.
  • Q/E or LB/RB switch tabs.
